# 有限元代码与实验结果说明

2026-10-07 修订版。本文件解释 `daizhan` 分支写了哪些代码、代码的数学含义，以及对**什么数据**得到**什么结果**。完整科研判断和文献见 [PDE/FEM 调研与本机实验](PDE_FEM_调研与本机实验.md)。

## 文件与职责

| 文件 | 写了什么、为什么 |
|---|---|
| `src/solvers/fem_solver.py` | `FiniteElementPFSolver.build()` 建相节点索引、按线路阻抗矩阵装配稀疏 P1 单元、检查不支持的元件、分解自由节点矩阵；`solve()` 用 PQ 电流注入迭代、Volt-VAR 外层迭代及上一时刻热启动，返回项目现有 `PFResult`。新增了物理线路长度 `ft/mi/km` 到线码阻抗单位的换算。 |
| `experiments/ieee13_derived_benchmark.py` | 从仓库里的 IEEE 13 线路数据提取明确删改的 9 条线路子网，生成双方可读的同一模型，运行 24 时刻，比较全节点电压、相角、支路电流、损耗、源功率、收敛；预热后交替顺序做 15 次重复计时。 |
| `experiments/fem_scaling_study.py` | 调用合成馈线生成器，生成 30/60/120/240 段网络，每档做 24 时刻、预热及 7 次交替顺序计时；检验误差和耗时随规模变化。 |
| `experiments/fem_radial_experiment.py` | 原始的合成长馈线生成器与单次对照演示；现把 OpenDSS 的 `Vminpu/Vmaxpu` 显式设置为恒 PQ 比较范围。单次耗时仅用于冒烟验证，科研结论以重复实验为准。 |
| `run.py` | 增加 `--solver fem`；默认仍是 OpenDSS。 |
| `requirements.txt` | 增加 SciPy 稀疏矩阵求解依赖。 |
| `README.md`、`.gitignore` | 写明实验入口和模型边界；不跟踪机器生成的输入/结果。 |
| `docs/PDE_FEM_调研与本机实验.md` | 文献区分、研究问题、实验设计、方法优缺点及下一步验证门槛。 |

## 求解器实际计算了什么

每条物理线路为一个 P1 单元，三相串联阻抗矩阵为 `Z_e`，对应单元块 `[[Z_e^-1,-Z_e^-1],[-Z_e^-1,Z_e^-1]]`。装配后给电源三相固定电压，在其余相节点迭代求解 `I=conj(S/V)`；稀疏 LU 在多时刻复用，PV 无功控制用外层迭代。对于常系数、无并联电纳线路，这与普通串联 `Ybus` **代数等价**。目前没有合并多段线路，也没有真正的 PDE 空间粗化。

## 数据和结果一：IEEE 13 线路数据派生子网

主要正确性算例保留公开 IEEE 13 数据中的 9 条线路的 R/X 矩阵、相别和长度，共 10 母线、25 相节点；使用项目现有 5 个负荷、6 个 DER 的 24 小时时序。为了让两个求解器求同一个问题，上游变压器与调压器换成 RG60 的固定 4.16 kV 电源；删去开关、电容、三角形负荷等不支持设备；611 负荷由原电压相关模型改为恒 PQ。**它不是未经修改的 IEEE 13 标准算例；DER 曲线来自项目数据，不是 IEEE 实测数据。**脚本及生成的 `summary.json` 明列全部删改。

| 指标 | 结果 |
|---|---:|
| 24 时刻的相节点观测 | 600 个，双方全部收敛 |
| 最大电压幅值差 | `1.19e-8 pu` |
| 电压幅值误差 95 分位 | `9.37e-9 pu` |
| 最大相角差 | `3.16e-7°` |
| 最大支路电流差 | `2.06e-6 A` |
| 最大损耗差 | `3.15e-7 kW` |
| 15 次重复 QSTS 中位数 | FEM `0.0359 s`；OpenDSS `0.0307 s` |

这个小网络上 OpenDSS 略快。数字评价的是当前代码与适配器，不是有限元对节点导纳法的理论优劣。

## 数据和结果二：合成馈线的规模压力测试

每段 0.12 km，三相不平衡单相负荷沿线分布，并有 PV/EV；24 时刻，每档 7 次重复计时。它只用于压力和规模规律，不能称为真实或 IEEE 馈线。

| 段数 / 相节点 | 最大电压差 pu | FEM QSTS 中位秒 | OpenDSS QSTS 中位秒 |
|---:|---:|---:|---:|
| 30 / 93 | `1.79e-10` | 0.0481 | 0.0574 |
| 60 / 183 | `3.60e-10` | 0.2491 | 0.3820 |
| 120 / 363 | `7.05e-10` | 0.5668 | 1.0478 |
| 240 / 723 | `1.52e-9` | 1.4830 | 3.8833 |

240 段时有低于 0.95 pu 的节点。最初出现 `0.00125 pu` 差异，是 OpenDSS 默认低电压负荷语义与 FEM 恒 PQ 不同造成；显式统一恒 PQ 后，最大差异降至 `1.52e-9 pu`。这说明比较之前必须严格对齐物理模型。即使此实现的合成规模计时较短，因为 P1 单元并未减少自由度，也**不能解释为 FEM 方法本身更快**。同日两轮计时的 60/120/240 段绝对耗时相差约 2–3 倍，且 60 段单轮样本内部出现跳变，说明本机 wall-clock 性能评估尚未达到论文级可控性；详见主报告。

## 复现和产物

```powershell
python -m pip install -r requirements.txt
python experiments/ieee13_derived_benchmark.py --repeats 15
python experiments/fem_scaling_study.py --sizes 30 60 120 240 --repeats 7 --hours 24
```

结果会生成于 `output/ieee13_derived_fem/` 和 `output/fem_scaling_study/`，包括原始计时样本和机器可读 `summary.json`；输入生成于 `work/`。这些可再生文件不纳入 Git。若运行完整 IEEE 13，求解器目前会对不支持的变压器、调压器、开关、并联电容等明确报错，不能用于完整系统的正式结论。
